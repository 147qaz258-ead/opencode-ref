# Test Skill

This is a test skill to verify that sandbox skill loading works correctly.

## Usage

When this skill is loaded, the agent should acknowledge that it has access to test-skill instructions.

## Expected Behavior

1. The skill should be discoverable via the `skill` tool
2. Loading this skill should inject this content into the conversation
3. In sandbox mode, this demonstrates project-local skill loading
