# UI 包结构映射 (UI Package Map)

这里展示了 `packages/ui` 文件夹的详细结构。这个包主要包含用户界面组件、样式和前端逻辑。
为了方便非技术背景人员理解，下表提供了核心文件夹的功能映射。

### 核心目录功能映射 (Functional Mapping)

| 目录/文件 (Directory) | 中文说明 (Description) | 功能用途 (Purpose) |
| :--- | :--- | :--- |
| **src** | 源代码 | 存放所有前端核心代码 |
| **assets** | 资源文件 | 存放字体、图标、Logo、音效等静态素材 |
| **components** | 组件库 | 构成界面的积木，如按钮、弹窗、侧边栏等 |
| **context** | 全局状态 | 管理跨页面的数据，如用户信息、当前主题 |
| **hooks** | 逻辑复用 | 封装通用的交互逻辑，如“滚动监听”、“键盘快捷键” |
| **pierre** | 差异对比 | 专门用于显示代码变更 (Diff) 的核心模块 |
| **styles** | 样式定义 | 定义颜色、字体大小、动画等视觉规范 (Tailwind) |
| **theme** | 主题配置 | 管理深色/浅色模式及代码高亮配色 |

---

### 完整目录结构 (Directory Structure)

```text
📁 ui
  📁 script # 构建脚本 (Tailwind 配置)
    📄 colors.txt
    📄 tailwind.ts
  📁 src # 源代码根目录
```
